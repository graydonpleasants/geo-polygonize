core(ci): fix automerge workflow by migrating to gh cli

The `daneden/enable-automerge-action` is deprecated and failed with 401
Bad Credentials because the token and permissions were insufficient.
This replaces the third-party action with the native `gh pr merge --auto`
CLI command, utilizes `github.token` instead of an invalid `secrets.GH_PAT`,
and explicitly declares the required `contents: write` and
`pull-requests: write` permissions. It also restricts the automerge to
only PRs from the approved author on the target repository using an
`if` condition.
